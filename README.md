# АСУ АТК (TransportCompany)

Автоматизированная система управления автотранспортным комплексом — Windows Forms приложение для комплексного управления операциями транспортной компании.

## Описание

Система предназначена для автоматизации учёта и управления транспортными операциями, включая:

- **Управление автопарком** — учёт техосмотров, ОСАГО, водительских удостоверений
- **Финансовый учёт** — расчёт заработной платы водителей, стоимости рейсов
- **Реестры перевозок** — импорт и редактирование данных о перевозках
- **Аналитика** — сравнение показателей, анализ зон обслуживания

## Архитектура

Приложение построено как модульный монолит со слоями (v2.0, ветка `redesign/architecture-refactor`):

```text
UI (WinForms)
  Shell/MainShellForm      — единственное главное окно: сайдбар + верхняя панель + контент
  Pages/*                  — страницы-модули (UserControl): Dashboard, Maintenance, Salary,
                             FleetDiary, Earnings, Import, Comparison, ZoneAnalysis, Settings
  Dialogs/*                — модальные диалоги (редактирование записей, расчётный листок и т.п.)
  Theme/*                  — дизайн-система: палитра, шрифты, стилизация контролов
        │
        ▼
Core
  Services/*               — бизнес-логика: PayrollService, EarningsService, ZoneAnalysisService,
                             RegistryImportService (+ парсеры Excel/HTML), ZoneRateService, ExpiryService
  Repositories/*           — доступ к данным: Maintenance, FleetDocuments, Registry, ZoneSettings
  Models/*                 — типизированные модели предметной области
  Data/*                   — IDbConnectionFactory, Db (обёртка ADO.NET, транзакции)
  Logging/AppLogger        — единый файловый журнал (%LocalAppData%\ATK-Forum\Logs)
        │
        ▼
SQL Server (TransportRegistry, Техобслуживание, OSAGO, DriverLicenses, ZoneSettings, ...)
```

Ключевые принципы:

- Формы не содержат SQL и бизнес-расчётов — только отображение и вызовы сервисов.
- **ZoneRateService — единственный источник тарифов зон** для всех расчётов
  (зарплата, заработок, сравнение, расчётный листок). Тарифы редактируются в «Настройках».
- Многошаговые изменения БД (импорт файла, сохранение тарифов) выполняются в транзакциях.
- Слои данных и конфигурации не показывают MessageBox — ошибки пробрасываются исключениями,
  UI показывает понятное сообщение, технические детали пишутся в журнал.
- Зависимости собираются вручную в `Program.cs` (composition root, класс `AppServices`).

## Структура базы данных

Схема создаётся скриптом [`Script.sql`](Script.sql). Скрипт **идемпотентный**: создаёт базу и
таблицы только при их отсутствии и не удаляет существующие данные; включает миграцию
для баз, созданных прежней версией скрипта.

Основные таблицы:

- **TransportRegistry** — реестр перевозок (рейсы: дата, водитель, ТС, зона, суммы)
- **ImportLog** — журнал импорта (одна запись на файл)
- **Техобслуживание** — техосмотры (`Номер машины`, `Дата последнего ТО`, `Пробег (км)`, `Комментарий`)
- **OSAGO** / **DriverLicenses** — полисы и удостоверения
- **Vehicles** / **Drivers** — справочники ТС и водителей
- **ZoneSettings** — тарифы зон 0–10 (используются во всех расчётах)
- **ZoneCostHistory** — аудит изменений тарифов

## Функциональность

### Главная страница

- Карточки всех модулей
- Панель «Требуют внимания»: истекающие ОСАГО и ВУ, просроченные ТО
  (проверки больше не блокируют запуск приложения)

### Модули

- **Техосмотр** — таблица ТО с поиском и фильтрами, добавление/редактирование/удаление,
  подсветка просроченных (ТО старше 3 месяцев)
- **Расчёт ЗП** — зарплата водителей за период; двойной клик по строке — расчётный
  листок по зонам; кнопка «Статистика водителя» — сводная статистика
- **Дневник Автопарка** — вкладки ОСАГО и водительских удостоверений со статусами
  («Действует» / «Истекает» / «Истёк»)
- **Заработок ТС и Водителей** — рейсы, суммы с/без НДС, зарплата; экспорт в Excel
- **Импорт Реестров** — выбор файлов или drag-and-drop (.xls/.xlsx/.html), асинхронный
  импорт с живым журналом, транзакция на файл, проверка дубликатов, журнал импорта из БД,
  редактирование реестра (обновление по стабильному ключу Id)
- **Сравнение ТС/Водителей** — 4 диаграммы: рейсы, зарплата, выручка с/без НДС
- **Анализ зон** — помесячные таблицы рейсов по зонам с процентами и графиками
- **Настройки** — тарифы зон (с валидацией и историей изменений), проверка и
  сохранение строки подключения
